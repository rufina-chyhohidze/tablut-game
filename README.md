# Tablut - team 12



## Getting started

Database configuration variables can be found inside .env
file in root directory. If you have another user or databse please make sure to update the credentials inside the file before starting the game.

Example for file .env 

```
    JDBC_POSTGRES_URL=jdbc:postgresql://localhost:5432/local      
    JDBC_POSTGRES_DB_USERNAME=postgres
    JDBC_POSTGRES_DB_PASSWORD=postgres
```

P.S 

We understand that saving .env file on GitLab is not the best practice. 

# Play

1) Start Main.java file
2) Enjoy!
